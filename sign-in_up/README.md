# WinForms Sign In & Registration Task

Bu layihə C# Windows Forms istifadə edərək hazırlanmış sadə Qeydiyyat (Registration) və Giriş (Sign In) sistemidir.

## 🚀 Xüsusiyyətlər
* **Qeydiyyat (Registration):** Yeni istifadəçi adı və şifrə daxil edilərək yaddaşa yazılır.
* **Giriş (Sign In):** Qeydiyyatdan keçmiş istifadəçi adı və şifrə ilə sistemə daxil olmaq mümkündür (İlkin olaraq `admin` / `admin123` təyin edilib).
* **Şifrəni Göstər/Gizlə (Show me password):** CheckBox seçildikdə şifrə görünür, seçilmədikdə gizlənir.
* **Xəbərdarlıqlar:** Səhv məlumat daxil edildikdə və ya boş xana qaldıqda uyğun xəbərdarlıq pəncərəsi (MessageBox) çıxır.

## 🛠 İstifadələr olunub
* **Dil:** C#
* **Platforma:** .NET / Windows Forms
* **Mühit:** Visual Studio
